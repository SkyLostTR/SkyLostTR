# Deepcore Miner: Gold Rush

A polished portrait 2.5D/3D claw-mining game for Android built with Godot 4.7.x.

Core loop: the claw swings automatically, the player taps to fire, catches underground objects, and hauls them back against a level timer and money target. Valuable objects build combo and charge an 8-second Gold Rush mode; heavy rocks can be discarded with dynamite.

Features include procedural level layouts, small/medium/large gold, diamonds, fossils, mystery caches, rocks and unstable TNT, weighted haul speeds, haptics, particles, procedural audio, level goals and stars, permanent rig upgrades, consumable dynamite, persistent local saves, editable miner identity and a shared online leaderboard.

The GitHub Actions build provisions and injects a shared prototype leaderboard endpoint, runs Godot import + runtime smoke validation, and exports an ARM64 Android APK.
