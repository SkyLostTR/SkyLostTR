# Deepcore Miner

Portrait 3D online mining game prototype for Android, built with Godot 4.7.x.

Features: procedural stylized cave, emissive crystals, lighting/shadows/fog, drill animation, mining particles and haptics, randomized ore tiers, depth progression, pick/auto-drill/cargo upgrades, offline earnings, persistent save, editable miner identity, shared online leaderboard, splash screen and Android app icon.

The CI build creates and injects a shared JSONBlob leaderboard endpoint for the prototype. For a production release, replace this with a server-authoritative API on your own backend.
